사용 방법

  1. 사진 칸을 클릭하거나 사진을 끌어다 놓으면 업로드됩니다. (자동으로 가볍게 줄여서 인터넷에 저장돼요)
  2. 이름·가격·설명을 적습니다. 가격은 10,900원처럼 자유롭게 적어도 됩니다.
  3. 다 바꿨으면 아래 「저장하기」를 누르세요. 곧바로 손님 홈페이지에 반영됩니다.
  4. 손님이 홈페이지를 새로고침하면 바뀐 내용이 보입니다.

※ GitHub에 파일을 다시 올릴 필요가 없습니다. 저장만 누르면 끝이에요.
