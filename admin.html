사용 방법

  1. 사진 칸을 클릭하거나 사진을 끌어다 놓으면 업로드됩니다. (자동으로 가볍게 줄여줘요)
  2. 이름·가격·설명을 적습니다. 가격은 10,900원처럼 자유롭게 적어도 됩니다.
  3. 다 바꿨으면 아래 「완성 파일 받기」를 누르세요. index.html이 받아집니다.
  4. 받은 index.html을 GitHub 저장소에 덮어쓰기로 올리면 끝! 손님들에게 반영됩니다.

※ 「미리보기 저장」은 이 기기 브라우저에서만 확인용입니다. 실제 사이트 반영은 완성 파일을 올려야 합니다.
