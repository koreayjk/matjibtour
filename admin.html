사용 방법

  1. 사진 칸을 클릭하거나 사진을 끌어다 놓으면 업로드됩니다. (자동으로 가볍게 줄여서 저장돼요)
  2. 이름·가격·설명을 적습니다. 가격은 10,900원처럼 자유롭게 적어도 됩니다.
  3. 다 바꿨으면 「저장하기」를 누르세요. 이 컴퓨터에서 미리보기로 바로 확인됩니다.
  4. 모든 손님에게 보이게 하려면 「🌐 모든 손님에게 발행」을 누르세요. (처음 한 번 「⚙️ 발행 설정」에서 GitHub 토큰만 넣어두면, 이후엔 버튼 한 번으로 끝!)

※ 발행 설정을 해두면 GitHub에 직접 올릴 필요 없이 자동으로 반영됩니다.

발행 설정 (처음 한 번만)

아래에 GitHub 토큰을 한 번만 넣어두면, 이후엔 「🌐 모든 손님에게 발행」 버튼만 눌러 자동으로 사이트에 반영됩니다. (토큰은 이 컴퓨터에만 저장돼요)

토큰 만드는 법 (눌러서 보기)
  1. GitHub 로그인 → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Generate new token → 이름 입력, 만료일 선택
  3. Repository access: Only select repositories → 이 저장소 선택
  4. Permissions → Repository permissions → Contents를 Read and write로 설정
  5. 생성된 토큰을 복사해 위 칸에 붙여넣고 저장
