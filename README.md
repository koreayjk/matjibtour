# 맛집여행 홈페이지 — 사용 안내

## 📁 파일 구성
- `index.html` — 손님들이 보는 홈페이지 (메인)
- `admin.html` — 사장님 전용 관리자 페이지
- `site-data.js` — 메뉴·사진·이벤트 데이터 (관리자가 자동 관리)
- `assets/` — 사진 폴더
- `.nojekyll` — GitHub Pages 설정 파일 (지우지 마세요)

이 폴더의 내용을 **통째로** GitHub 저장소에 올리면 됩니다.

---

## 🔑 관리자 페이지 들어가기
주소창에 홈페이지 주소 뒤에 `/admin.html`을 붙이세요.
예) `https(콜론)//내아이디.github.io/저장소이름/admin.html`

- 비밀번호: **2414**

---

## ✏️ 사진·메뉴·이벤트 바꾸는 법
1. 관리자 페이지에 들어가 비밀번호(2414)를 입력합니다.
2. 위쪽 탭에서 **대표 메뉴 / 매장 사진 / 이벤트·소식** 중 고릅니다.
3. 사진 칸을 **클릭**하거나 사진을 **끌어다 놓으면** 업로드됩니다. (자동으로 가볍게 줄여줍니다)
4. 이름·가격·설명을 자유롭게 적습니다.
5. 다 바꿨으면 맨 아래 **「완성 파일 받기」** 버튼을 누릅니다 → `index.html`이 다운로드됩니다.
6. 받은 `index.html`을 GitHub 저장소에 **덮어쓰기(같은 이름으로 다시 올리기)** 하면 끝!
   잠시 후 손님들 화면에 반영됩니다.

> 💡 **「미리보기 저장」** 은 내 기기(브라우저)에서 확인용으로만 보입니다.
> 실제로 손님들에게 반영되려면 **완성 파일을 꼭 GitHub에 올려야** 합니다.

---

## ⚠️ 주의할 점
- 사진을 너무 많이/크게 넣으면 파일이 무거워집니다. 화면 아래 용량 표시가 **빨간색**이 되면 사진 몇 개를 줄이거나 빼주세요.
- 비밀번호 2414는 가족·지인이 실수로 건드리는 것을 막는 정도입니다. (완벽한 보안은 아닙니다)
- `admin.html`은 검색에 안 잡히도록 설정되어 있지만, 주소를 아는 사람은 접근할 수 있습니다.
