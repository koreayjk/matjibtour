# 맛집여행 홈페이지 — 사용 안내 (Supabase 없이 동작)

서버(Supabase) 없이 **순수 정적 사이트**로 동작합니다. GitHub Pages에 올리기만 하면 됩니다.

## 📁 파일 구성
- `index.html` — 손님들이 보는 홈페이지
- `admin.html` — 사장님 전용 관리자 페이지
- `storage.js` — 데이터 저장소(브라우저 localStorage) 공통 설정 (건드리지 마세요)
- `site-data.js` — 손님 모두에게 보이는 기본 데이터
- `assets/` — 기본 사진 폴더
- `.nojekyll` — GitHub Pages 설정 (지우지 마세요)

이 폴더 전체(index.html, admin.html, storage.js, site-data.js, assets/, .nojekyll)를
GitHub 저장소에 올립니다. 끝!

> 더 이상 Supabase 가입·SQL 실행이 필요 없습니다.

## 사진·메뉴 바꾸는 법

1. 주소창에 홈페이지 주소 뒤에 `/admin.html`을 붙여 들어갑니다.
   예) `https://내아이디.github.io/저장소이름/admin.html`
2. 비밀번호 **2414** 입력
3. 탭(첫 화면 / 대표 메뉴 / 소개 사진 / 매장 사진 / 이벤트·소식)에서 원하는 것을 고릅니다.
4. 사진 칸을 클릭하거나 사진을 끌어다 놓으면 업로드됩니다. 이름·가격·설명을 적습니다.

### ① 「💾 저장하기 (이 기기에 반영)」
- 지금 쓰는 **이 컴퓨터(브라우저)에서만** 바로 미리보기로 확인됩니다.
- 다른 손님 기기에는 아직 반영되지 않습니다. (빠르게 확인하는 용도)

### ② 「🌐 모든 손님에게 발행」  ← 손님 모두에게 보이게 하려면 이걸로!
- 버튼을 누르면 **GitHub에 자동으로 반영**됩니다. (1~2분 뒤 모든 손님에게 보임)
- 사진은 `assets/uploads/` 폴더에 파일로 올라가고, `site-data.js`는 가볍게 유지됩니다.

#### 발행 설정 (처음 한 번만)
관리자 페이지 위쪽 **「⚙️ 발행 설정」**에서 GitHub 토큰을 한 번만 넣어두면 됩니다.

1. GitHub → **Settings → Developer settings → Personal access tokens → Fine-grained tokens**
2. **Generate new token** → 이름·만료일 설정
3. **Repository access** → *Only select repositories* → 이 저장소 선택
4. **Permissions → Repository permissions → Contents** → **Read and write**
5. 만들어진 토큰을 복사해 「발행 설정」 칸에 붙여넣고 저장

> 토큰은 **사장님 컴퓨터(브라우저)에만** 저장되며 사이트에 노출되지 않습니다.
> 토큰을 넣기 싫으면 「발행 설정 → 파일로 받기」로 `site-data.js`를 받아 직접 GitHub에 올려도 됩니다.

## 이미지 최적화
- 업로드한 사진은 자동으로 긴 변 **1000px 이하**로 단계적으로 축소됩니다.
- 브라우저가 지원하면 **WebP**로 인코딩해 JPEG보다 **25~35% 더 작게** 저장합니다.
- 발행 시 사진은 base64가 아닌 **실제 이미지 파일**로 올라가, 손님 페이지가 빠르고 캐시도 잘 됩니다.

## 참고
- Supabase 같은 서버 없이 동작합니다. 발행은 GitHub API로 직접 이뤄집니다.
- 비밀번호 2414는 가족·지인이 실수로 건드리는 것을 막는 정도입니다.
- 「저장하기」용 브라우저 미리보기 데이터가 너무 커지면(발행 전 사진이 매우 많을 때) 저장 경고가 뜰 수 있습니다.
  그럴 땐 먼저 「발행」을 해서 사진을 파일로 옮기면 가벼워집니다.
