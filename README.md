# 맛집여행 홈페이지 — 사용 안내 (Supabase 없이 동작)

서버(Supabase) 없이 **순수 정적 사이트**로 동작합니다. GitHub Pages에 올리기만 하면 됩니다.

## 📁 파일 구성
- `index.html` — 손님들이 보는 홈페이지
- `admin.html` — 사장님 전용 관리자 페이지
- `storage.js` — 데이터 저장소(브라우저 localStorage) 공통 설정 (건드리지 마세요)
- `site-data.js` — 손님 모두에게 보이는 기본 데이터
- `assets/` — 기본 사진 폴더
- `.nojekyll` — GitHub Pages 설정 (지우지 마세요)

---

## 🟢 처음 준비 (딱 1단계)

이 폴더 전체(index.html, admin.html, storage.js, site-data.js, assets/, .nojekyll)를
GitHub 저장소에 올립니다. 끝!

> 더 이상 Supabase 가입·SQL 실행이 필요 없습니다.

---

## 사진·메뉴 바꾸는 법

관리자 페이지의 저장 방식은 **두 가지**입니다.

1. 주소창에 홈페이지 주소 뒤에 `/admin.html`을 붙여 들어갑니다.
   예) `https://내아이디.github.io/저장소이름/admin.html`
2. 비밀번호 **2414** 입력
3. 탭(첫 화면 / 대표 메뉴 / 소개 사진 / 매장 사진 / 이벤트·소식)에서 원하는 것을 고릅니다.
4. 사진 칸을 클릭하거나 사진을 끌어다 놓으면 업로드됩니다. 이름·가격·설명을 적습니다.

### ① 「저장하기 (이 기기에 반영)」
- 지금 쓰는 **이 컴퓨터(브라우저)에서만** 바로 미리보기로 확인됩니다.
- 다른 손님 기기에는 아직 반영되지 않습니다. (빠르게 확인하는 용도)

### ② 「모든 손님에게 반영 (파일 받기)」  ← 손님 모두에게 보이게 하려면 이걸로!
- 누르면 `site-data.js` 파일이 내려받아집니다.
- 이 파일을 **GitHub 저장소에 같은 이름으로 덮어쓰기**로 올리면(업로드),
  모든 손님 기기에 똑같이 반영됩니다.

## 참고
- 사진은 자동으로 가볍게 줄여서 저장됩니다.
- Supabase 같은 서버가 없으므로, **손님 모두에게 반영하려면 `site-data.js`를 GitHub에 올리는 단계**가 필요합니다.
- 비밀번호 2414는 가족·지인이 실수로 건드리는 것을 막는 정도입니다.
- 브라우저에 저장되는 미리보기 데이터가 너무 커지면(사진이 매우 많을 때) 저장 경고가 뜰 수 있습니다.
  그럴 땐 사진 수를 줄이거나 더 작은 사진을 쓰세요.
