# 맛집여행 홈페이지 — 사용 안내 (Supabase 연동판)

## 📁 파일 구성
- `index.html` — 손님들이 보는 홈페이지
- `admin.html` — 사장님 전용 관리자 페이지
- `supabase-config.js` — Supabase 연결 설정 (건드리지 마세요)
- `site-data.js` — 처음 보여줄 기본 데이터 (Supabase에 데이터가 없을 때만 사용)
- `supabase_설정.sql` — **처음 한 번만** Supabase에 붙여넣어 실행할 설정
- `assets/` — 기본 사진 폴더
- `.nojekyll` — GitHub Pages 설정 (지우지 마세요)

---

## 🟢 처음 한 번만 하는 준비 (딱 2단계)

### 1단계 — Supabase에 테이블·사진저장소 만들기
1. supabase.com 로그인 → 기존 프로젝트(교회 홈페이지에 쓰던 그 프로젝트) 선택
2. 왼쪽 메뉴 **SQL Editor** → **New query** 클릭
3. `supabase_설정.sql` 파일 내용을 **전체 복사**해서 붙여넣기
4. **Run(실행)** 클릭 → "Success" 나오면 완료!

### 2단계 — GitHub에 파일 올리기
이 폴더 전체(index.html, admin.html, supabase-config.js, site-data.js, assets/, .nojekyll)를
GitHub 저장소에 올립니다. (supabase_설정.sql과 이 README는 올려도 되고 안 올려도 됩니다)

> 준비 끝! 이제부터는 관리자 페이지에서 저장만 누르면 바로 반영됩니다.

## 평소에 사진·메뉴 바꾸는 법 (매번 GitHub 안 올려도 됨!)
1. 주소창에 홈페이지 주소 뒤에 `/admin.html`을 붙여 들어갑니다.
   예) https(콜론)//내아이디.github.io/저장소이름/admin.html
2. 비밀번호 2414 입력
3. 탭(대표 메뉴 / 매장 사진 / 이벤트·소식)에서 원하는 것 선택
4. 사진 칸을 클릭하거나 사진을 끌어다 놓으면 업로드됩니다.
5. 이름·가격·설명을 적습니다.
6. 맨 아래 「저장하기」 누르면 → 곧바로 손님 홈페이지에 반영!
   (손님이 새로고침하면 바뀐 내용이 보입니다)

## 참고
- 사진은 Supabase에 안전하게 저장되고, 모든 손님 기기에서 똑같이 보입니다.
- 비밀번호 2414는 가족·지인이 실수로 건드리는 것을 막는 정도입니다.
- 만약 "저장 실패" 메시지가 나오면 → 1단계 SQL을 실행했는지 다시 확인해 주세요.
- Supabase 무료 요금제는 저장공간 1GB, 사진 충분히 많이 올릴 수 있습니다.
